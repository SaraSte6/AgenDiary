# AgenDiary

AgenDiary is a student project from the Object-Oriented Programming course at the University of Padua.
The program helps you organize your personal activities — like tasks, events, appointments, and deadlines — using a simple graphical interface made with Qt.

## What you can do

* Add, edit, and remove activities
* View details for each item
* The program currently supports:
   * Tasks
   * Events
   * Appointments
   * Deadlines
   * Reminders

Some activity types share common information, and the code uses some common programming techniques (like Visitor) to make it easy to extend with new activity types or details in the future.

## How to run

1. Build the app using Qt Creator or by running `qmake` and `make` (`.pro` is included)
2. Start the app (`AgenDiary` or `AgenDiary.exe`)
